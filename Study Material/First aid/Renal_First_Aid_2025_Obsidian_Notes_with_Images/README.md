# Renal — First Aid 2025 — Obsidian Package

This folder contains the five renal Markdown notes supplied by the user, prepared for Obsidian with embedded visual references from the uploaded *First Aid for the USMLE Step 1 (2025)* PDF pages 616–649.

## Files

- `01_Renal_Embryology.md`
- `02_Renal_Anatomy.md`
- `03_Renal_Physiology.md`
- `04_Renal_Pathology.md`
- `05_Renal_Pharmacology.md`

## Images

Visual assets are in `assets/renal-first-aid-2025/`.

The embeds use Obsidian's native image wikilink syntax and relative paths, so the folder can be copied directly into an Obsidian vault.

The package uses the extracted figure crops and vector-only page renders as the visible study-note images. The raw PDF image-object fragments were not inserted separately because many are constituent pieces of composite figures and would create duplicated/fragmented visuals.
