ENT Prep XI — semantically named figure crops

Contains 420 individual figure/image crops from a 204-page ENT Prep XI PDF. Filenames include the source PDF page and a descriptive subject label inferred from visible labels, OCR, and visual review. Labels are cautious where the original crop is ambiguous or fragmented.

- images/: renamed JPG crops
- IMAGE_INDEX.md: descriptive index and Obsidian embed syntax
- manifest.csv: source page, figure number, crop geometry, new filename, description, OCR hint
- renaming_map.csv: old-to-new filename map
- page_summary.csv: per-page crop counts
- contact_sheets/: preview sheets labelled with the new filenames
- sample_overlays/: original sample detection overlays

Obsidian: the index lists embeds as `![[images/FILENAME.jpg]]`. If you link from a note elsewhere in the vault, adjust the path to include this folder name if required by your vault's link settings.

Accuracy note: filenames describe the visible subject, but do not certify a clinical diagnosis. Some source crops are fragments or may have imperfect boundaries; use the contact sheets to review them.
