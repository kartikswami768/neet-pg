# PREP XI Physiology — Chapters 21–60

This is a combined Obsidian-ready package for chapters 21 through 60 of the PREP XI Physiology notes.

## Contents

- 40 standalone chapter Markdown notes, named by chapter number and topic
- `images/` with 325 figure crops referenced by the notes
- `INDEX.md` for navigation and original page assignments
- `manifest.csv` for per-chapter packaging and QA status
- `QA_REPORT.md` describing compilation checks and remaining verification limits
- `integrity_checks.json` with machine-generated packaging checks

## Install in Obsidian

1. Extract the ZIP.
2. Move the resulting `Physiology_Prep_XI_Chapters_21-60` folder to the desired location in your vault (or copy its contents together into a target subject folder).
3. Keep the `images` folder beside the Markdown notes. Do not separate it from the notes; embedded figures depend on those relative paths.
4. Open `INDEX.md` to navigate the chapters.

**QA note:** package links, file coverage and structural checks are validated; this does not mean every original source statement or reconstructed crop has been fully re-proofread. See `QA_REPORT.md`.
