# absence Seizure
Age Group 5 - 8 years
## clinical features
1. Blank vacant stare +- Lip Smacking
2. Post Ictal Phase is absent
3. Scholastic performance

## EEG
3 Hz spike wave complexes

## provocation
Hyperventilation

## DOC
Typical Seizure: Ethosuximide
Atypical AS (AS + other seizure type) Valproate

# JME (Juvenile Myoclonic Epilepsy) aka JAN Syndrome
- AGE: Adolescent Female
- GENETICS: polygenic inheritence eg, GABRA 1, CLCN, Myollonin
## Clinical Features
- on waking up $\rightarrow$ Myoclonic jerks, drop attacks (drops things)
- 1/3 have absence seizure
- Lifelong Condition
### Provocation:
1. Lack of sleep
2. Alcohol

### EEG
4-6 hz polyspike 

### DOC
Valproate
