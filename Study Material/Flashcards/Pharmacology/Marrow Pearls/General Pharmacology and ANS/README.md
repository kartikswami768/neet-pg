# Marrow Pearls — General Pharmacology & ANS

This folder contains one Markdown note per Marrow Pearl reconstructed from the uploaded General Pharmacology + Autonomic Nervous System scan.

## Metadata

- `pearl_id` — original Marrow Pearl ID.
- `Subject` — one YAML property; multiple subject values are stored as one list when required.
- `Topic` — one YAML property; full topic names are used, with common short forms such as `ANS`, `CNS`, and `CVS` included as additional values where useful.
- `tags` — searchable subject/topic/Marrow/flashcard tags.

## Images

Only actual educational figures embedded in the Pearls are stored as images. Full-page scanned screenshots are not included.

- PMO687: neuromuscular-transmission diagram
- PM2378: zero-order vs first-order elimination kinetics figure

## Spaced repetition

Each Pearl note contains a multi-line flashcard using the `Question ? Answer` format and the hierarchical deck tag `#flashcards/Pharmacology/Marrow-Pearls/General-Pharmacology-ANS`.
