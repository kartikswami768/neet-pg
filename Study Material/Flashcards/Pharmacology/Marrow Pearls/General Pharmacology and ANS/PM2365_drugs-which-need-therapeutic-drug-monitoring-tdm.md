# Drugs which need Therapeutic Drug Monitoring (TDM)

**Pearl ID:** `PM2365`

#flashcards/Pharmacology/Marrow-Pearls/General-Pharmacology-ANS

What are the key facts in the Marrow Pearl **"Drugs which need Therapeutic Drug Monitoring (TDM)"** (PM2365)?
?

Drugs with a narrow therapeutic index require therapeutic drug monitoring (TDM).

The mnemonic **"DATLAAT MC"** can be used.

- **D:** Digoxin
- **A:** Anti-arrhythmic
- **L:** Lithium
- **A:** Aminoglycosides
- **T:** Theophylline
- **A:** Anti-epileptics
- **T:** Tricyclic antidepressants
- **M:** Methotrexate
- **C:** Calcineurin inhibitors
