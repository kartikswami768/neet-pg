# Marrow Pearls — Pharmacology (General Pharmacology + Autonomic Nervous System)

This package contains **32 separate Markdown files**, one per unique Marrow Pearl in the uploaded 44-page scan.

## Processing notes

- Pearl boundaries were determined by **Pearl ID**, not by page breaks. Multi-page pearls were consolidated into a single Markdown file.
- Text was transcribed from the **visible scan**, with obvious OCR corruption corrected where the scan unambiguously supported the reading.
- The source scan is linked back into every Pearl file through one or more page images in `images/`.
- Page 44 is a duplicate of Pearl `PM2136` on page 1 and is therefore not treated as a second Pearl.
- The content is a **source-faithful transcription**, not an independent medical fact-check. No external material was added to change the teaching point.
- `subject_ids` and `topic_ids` are normalized identifiers added for organization; `source_subjects` / `source_topics` preserve the classification shown on the scan.
