# Marrow Pearls — Pharmacology PDF 3

This package contains the Marrow Pearls extracted from the uploaded 45-page Pharmacology PDF.

## Contents

- 25 individual Markdown files, one per Pearl
- `index.md` for navigation
- `manifest.csv` with Pearl IDs, titles, source pages and associated images
- 6 extracted educational figures/diagrams in `images/`
- YAML frontmatter follows the supplied sample Pearl structure, including `Subject`, `type`, `Topic`, and `tags`.
- Images are embedded in the relevant Markdown notes using Obsidian wikilink syntax.

## Image handling

The package includes only the actual educational figures/diagrams, not full scanned PDF pages.
