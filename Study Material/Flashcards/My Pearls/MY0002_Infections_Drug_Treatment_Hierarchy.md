# Infection-wise antimicrobial treatment map

**How to read this table:** “DOC / preferred” is used only where the source explicitly gives that priority. “Alternatives / 2nd line” means alternatives actually named in the source; where no ranking is supplied, the entry says so instead of inventing one.

## Important source-level caveat

This file contains several explicit updates and corrections (for example, modern C. difficile therapy, gonorrhea/chlamydia treatment, carbapenemase therapy, and empiric meningitis therapy). Those updates are retained here. For infections where the source only gives a drug–disease association, the table does **not** manufacture a “first-line/second-line” hierarchy.
