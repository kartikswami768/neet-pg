## Daily execution model

### Block A — Consume
Read the planned note set for **coverage**, not rewriting.

### Block B — Retrieve
Close the notes and reproduce:
- classifications
- hallmark signs
- differentiating features
- investigations
- first-line treatment / management
- image-based diagnoses

### Block C — PYQs
Do Ophthalmology PYQs / incorrects for the day's topics.

Label each miss as:
- knowledge gap
- confusion
- careless error
- recall failure

### Block D — Repair
Return to the canonical notes only for gaps exposed by retrieval/PYQs.

> [!warning] Hard rule
> No repository reorganisation during this cycle. Use **consume → retrieve → test → repair**.
