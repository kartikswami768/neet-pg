## Daily execution model

### Block A — First pass
Read the planned module for **coverage**, not note rewriting.

### Block B — Retrieval
Close the notes and reproduce:
- classifications
- mechanisms
- prototype drugs
- hallmark adverse effects
- contraindications
- important interactions
- classic clinical uses

### Block C — PYQs
Do the corresponding Pharmacology PYQs and label misses as:
- knowledge gap
- confusion between two drugs/classes
- careless error
- recall failure

### Block D — Repair
Return to the canonical notes only for gaps exposed by Blocks B/C.

> [!warning] Hard rule
> Do not spend the five-day preparation window reorganising Pharmacology notes. The repository already contains the study documents. The job is **consume → retrieve → test → repair**.
