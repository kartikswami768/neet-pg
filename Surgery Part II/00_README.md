## Suggested revision order
1. Read each chapter's **clinical approach and mechanism** sections before memorizing named conditions.
2. Learn **all comparison tables and procedures**.
3. Review **Mermaid diagnostic pathways** as flowcharts in Obsidian.
4. Practice identifying histologic/imaging clues with your existing source images.
5. Check the **source-concordance appendix** before treating simplified exam rules as clinical recommendations.
