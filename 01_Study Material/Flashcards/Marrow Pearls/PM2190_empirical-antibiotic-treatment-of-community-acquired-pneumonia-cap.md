# Empirical Antibiotic Treatment of Community-Acquired Pneumonia (CAP)

Pearl ID: PM2190

#flashcards

**What are the key facts in the Marrow Pearl "Empirical Antibiotic Treatment of Community-Acquired Pneumonia (CAP)" (PM2190)?**

?

| Situation | Treatment regimen |
|---|---|
| **Outpatient — previously healthy** | Amoxicillin + macrolide / doxycycline **or** monotherapy with doxycycline |
| **Outpatient — comorbidities** | Respiratory fluoroquinolone **or** amoxicillin/clavulanate or a cephalosporin + macrolide / doxycycline |
| **Inpatient — non-ICU** | Respiratory fluoroquinolone **or** β-lactam + macrolide / doxycycline |
| **Inpatient — ICU** | β-lactam + respiratory fluoroquinolone **or** azithromycin |
| **If Pseudomonas** | Antipseudomonal β-lactam + fluoroquinolone **or** aminoglycoside |
| **If CA-MRSA** | Site-based regimen + Linezolid **or** Vancomycin |

### Notes
- Macrolides: **Azithromycin / Clarithromycin**
- Respiratory fluoroquinolones: **Levofloxacin / Moxifloxacin / Gemifloxacin** (Gemifloxacin only outpatient).
- **Ciprofloxacin** is an antipseudomonal fluoroquinolone; the Pearl states it should be used only with an antipseudomonal β-lactam for Pseudomonas coverage, not as a routine respiratory fluoroquinolone for CAP.
- β-lactam examples:
  - Outpatient with comorbidities: PO amoxicillin ± clavulanate / cefpodoxime / cefuroxime; IV ceftriaxone.
  - Inpatient, non-ICU: ampicillin / ceftriaxone / cefotaxime / ertapenem.
  - Inpatient, ICU: ampicillin-sulbactam / ceftriaxone / cefotaxime.
  - Antipseudomonal β-lactams: piperacillin-tazobactam / cefepime / imipenem / meropenem.
- Aminoglycosides: **Amikacin / Tobramycin**.
- The Pearl notes that **β-lactam + macrolide is preferred over β-lactam + fluoroquinolone**.
