## Vaughan-Williams classes shown in the pearl

### Class I - Na⁺ channel blockers
- **Class IA:** Procainamide, Quinidine, Disopyramide
- **Class IB:** Lidocaine, Mexiletine
- **Class IC:** Flecainide, Propafenone, Moricizine

### Class II - β-blockers
- Propranolol
- Esmolol

### Class III - K⁺ channel blockers
- Amiodarone
- Dronedarone
- Dofetilide
- Sotalol
- Ibutilide
- Vernakalant

### Class IV - Ca²⁺ channel blockers
- Verapamil
- Diltiazem

### Mechanism and effect on action-potential duration
| Class | Mechanism of action | Effect on action potential duration |
|---|---|---|
| IA | Na⁺ channel blockers with significant K⁺ channel blocking property | Prolonged |
| IB | Na⁺ channel blockers with K⁺ channel opening property | Shortened or no effect |
| IC | Na⁺ channel blockers with negligible K⁺ channel blocking property | Variable or no effect |
| II | β-blockers | Prolonged |
| III | K⁺ channel blockers | Prolonged |
| IV | Ca²⁺ channel blockers | - |

### Miscellaneous
| Drug | Mechanism | Effect |
|---|---|---|
| Adenosine | Activates adenosine receptors | Shortened |
| Digoxin | Na⁺-K⁺ ATPase inhibitor | Increases AV node refractoriness |
| Magnesium | Unknown | - |
