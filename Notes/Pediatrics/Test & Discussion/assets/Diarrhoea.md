## Diarrhoea Management
1. Deghydration
2. Zinc: 
	1. < 6 mo: 10 mg OD x 14 days
	2. > 6 mo: 20 mg OD , 14 days

TO make dehydrastion dignosis: you need **2 out of 4** things below: 

| Dehydration   | No        | Some             | Severe                |
| ------------- | --------- | ---------------- | --------------------- |
| Consciousness | normal    | irritable        | Lethargic             |
| Thirst        | normal    | Increased        | Unable to drink water |
| Skin pinch    | Normal    | Goes back Slowly | Very Slowly           |
| Eyes          | normal    | Sunken           | Very Sunken           |
|               |           |                  |                       |
| Plan          | Plan A    |                  |                       |
| Water Loss    | <50 ml/kg | 50-100 ml/kg     | >100 ml/kg            |
### Plan A
Replace ongoing Stool Losses with ORS
With each loose stool $\rightarrow$ 10 ml/kg ORS


| WHO ORS |     |
| ------- | --- |
| Na      | 75  |
| Glucose | 75  |
| K       | 20  |
| Cl      | 65  |
| Citrate | 10  |
| Toatal  | 245 |
### Plan B
Rehydrate $\rightarrow$ 75 ml/kg ORS over 4 hour (Oral NG) + replace ongoing fluid Loss (10 ml/kg ORS with Each Loose stool)

### Plan C
Use IVF $\rightarrow$ RL with 5% Dextrose > RL > NS


|          | 30 ml/kg | 70 ml/kg | total (100 ml/kg) |
| -------- | -------- | -------- | ----------------- |
| > 1 hour | 0.5 hour | 2.5 hour | 3 hour            |
| < 1 hour | 1 hour   | 5 hour   | 6. Hour           |
Then REplace ongoing stool losses
