## IMNCI Management
It is done at Primary Health Center only

| Classify         | Features                                                                                                                        | Treatment                                                                  |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| No Pneumonia     | - Only Cough/Cold<br>- No Features s/o Pneumonia<br>- Wheeze +/-                                                                | Soothing Measures<br>- if wheeze: give salbutamol                          |
| Pneumonia        | **1. Fast Breathing Pneumonia<br><br>2. Chest Indrawing Pneumonia**                                                             | - Oral Amox x 5 days<br>- Follow up after 2 days<br>- Explain Danger Signs |
| Severe Pneumonia | Stridor in an otherwise Calm Child<br><br>OR<br><br>1. High Grade fever<br>2. Poor feeding<br>3. Convulsions<br>4. Fall in SpO2 |                                                                            |
