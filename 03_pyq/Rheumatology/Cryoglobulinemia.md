# CRYOGLOBULINEMIA 

## Definition
**Cryoglobulins** are **immunoglobulins that precipitate at temperatures < 37 °C and redissolve on warming**.

👉 **Cryoglobulinemia** = presence of these proteins in serum  
👉 **[Cryoglobulinemic vasculitis](Vasculitis.md)** = immune-complex–mediated **small-vessel vasculitis** due to cryoglobulin deposition

---

## Classification (MUST KNOW)
### **Brouet classification** (exam favorite)

| Type                 | Immunoglobulin type                           | Key associations                                               | Pathogenesis                           | Complement | RF  |
| -------------------- | --------------------------------------------- | -------------------------------------------------------------- | -------------------------------------- | ---------- | --- |
| **Type I (Simple)**  | Monoclonal Ig (IgM or IgG)                    | ==Multiple myeloma==, Waldenström macroglobulinemia            | **Hyperviscosity, vascular occlusion** | Normal     | ❌   |
| **Type II (Mixed)**  | Monoclonal IgM (RF activity) + polyclonal IgG | ==**Hepatitis C (most common)**, HBV==                         | Immune-complex vasculitis              | **↓ C4**   | ✅   |
| **Type III (Mixed)** | Polyclonal IgM + polyclonal IgG               | ==Autoimmune diseases== (SLE, RA, Sjogren), chronic infections | Immune-complex vasculitis              | **↓ C4**   | ✅   |

📌 **Type II & III = “Mixed cryoglobulinemia”**

TYPE I: Malignant —> everything Monoclonal —>
	A. Large amount: Hyperviscosity
	B. Bad quality: Don’t have RF activity, can’t lower complement
TYPE II: Infection —> generates Monoclonal IgM —> acts as RF —> attacks various IgG and C4
TYPE III: Autoimmune disease —> generates various bad Ig —> act as RF —> attacks various Ig and C4

---

## Pathogenesis 
- Cryoglobulins form **immune complexes**
- Deposit in small vessels
- Activate **classical complement pathway**
- Cause **leukocytoclastic vasculitis**

🧪 Hallmark lab:
> **Low C4 with normal/near-normal C3**

---

## Clinical Features

### Meltzer’s triad ⭐⭐⭐
1. **Palpable purpura**
2. **Arthralgia**
3. **Weakness**

### Organ involvement
- **Skin**: Purpura, ulcers, Raynaud’s
- **Kidney**: **[Membranoproliferative GN (MPGN Type I)](Membranoproliferative%20Glomerulonephritis.md)**
- **Nerves**: Peripheral neuropathy (mononeuritis multiplex)
- **Joints**: Non-erosive arthritis

⚠️ **Type I behaves differently** → ischemia, gangrene, acrocyanosis

## Treatment (conceptual, exam-oriented)

### Treat the cause
- **HCV → Direct-acting antivirals (DAAs)**

### Immunosuppression (if vasculitis)
- Steroids
- Rituximab (CD20 B-cell depletion)
- Plasmapheresis (severe, life-threatening cases)

📌 Type I → treat underlying **plasma cell dyscrasia**

---

## Key Differentiating Points (EXAM TRAPS)

| Feature | Cryoglobulinemia |
|------|----------------|
| Vasculitis type | Small-vessel |
| Complement | **Low C4** |
| Strongest association | **Hepatitis C** |
| Renal lesion | MPGN |
| RF positivity | Type II & III |
| Hyperviscosity | Type I |

---

## One-Line Killers (memorize these)
- **Most common cryoglobulinemia** → Type II (mixed)  
- **Most common cause** → Hepatitis C  
- **Most sensitive complement abnormality** → Low C4  
- **Classic renal lesion** → MPGN  
- **Triad** → Purpura + Arthralgia + Weakness
